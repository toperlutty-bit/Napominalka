💊 Напоминалка

Сайт присылает маме напоминания выпить таблетки по графику. Расписание хранится в вашем приватном репозитории GitHub. Настройка — один раз:

  1. Создайте приватный репозиторий с именем napominalka-data (галочка Private, остальное по умолчанию).
  2. Создайте ключ доступа (Fine-grained token):
    • Expiration — No expiration (или 1 год);
    • Repository access — Only select repositories → napominalka-data;
    • Permissions → Repository permissions → Contents: Read and write;
    • Generate token и скопируйте его.
  3. В репозитории Napominalka: Settings → Secrets → Actions → New repository secret, имя DATA_TOKEN, значение — тот же ключ. Это нужно, чтобы рассылка сама читала расписание.
  4. Вставьте ключ сюда:

Ключ хранится только в этом браузере.

  1. Отправьте маме ссылку ниже (в WhatsApp, Telegram, СМС) и откройте её на iPhone в Safari.
