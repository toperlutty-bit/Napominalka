# 🌐 Сайт-напоминалка о таблетках

Сайт сам присылает маме push-уведомления на iPhone по графику, который вы настраиваете.
Ничего устанавливать из App Store и через Xcode не нужно.

## Как это работает

- **Страница настроек** (`/admin`, защищена паролем): вы добавляете лекарства, время приёма,
  дни недели, настраиваете повторные напоминания.
- **Страница мамы** (секретная ссылка `/m/…`): мама добавляет её на экран «Домой» iPhone,
  один раз разрешает уведомления. На странице крупно:
  - **«✅ Выпила»** — отметить приём (повторные напоминания отменяются);
  - **«💊 Закончились таблетки»** — рассылка по этому лекарству **встаёт на паузу**,
    а вам приходит уведомление «У мамы закончились таблетки»;
  - **«🛒 Купила, напоминать снова»** — возобновить рассылку (это же можно сделать на странице настроек кнопкой «Купили»).
- Каждую минуту сайт проверяет расписание и отправляет:
  - маме — напоминание в назначенное время;
  - маме — повтор через 15 минут (настраивается), если она не нажала «Выпила»;
  - вам — сообщение, если приём так и не отмечен (можно выключить).

Работает на **Cloudflare Workers** — бесплатно, сайт работает круглосуточно без вашего компьютера.

## Установка (один раз, ~15 минут, можно с телефона)

1. Зарегистрируйтесь на [cloudflare.com](https://dash.cloudflare.com/sign-up) (бесплатно).
   Зайдите в раздел **Workers & Pages** один раз — Cloudflare попросит выбрать имя поддомена `*.workers.dev`.
2. Создайте API-токен: **My Profile → API Tokens → Create Token →** шаблон
   **«Edit Cloudflare Workers»** → *Continue* → *Create Token*. Скопируйте токен.
3. На GitHub в этом репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `CLOUDFLARE_API_TOKEN` — токен из шага 2;
   - `CLOUDFLARE_ACCOUNT_ID` — ID аккаунта (Cloudflare → Workers & Pages → справа «Account ID»).
4. Влейте pull request в `main` (или запустите вручную: **Actions → Site — tests & deploy → Run workflow**).
   Через пару минут сайт будет доступен по адресу `https://napominalka.<ваш-поддомен>.workers.dev`.
5. Откройте `https://napominalka.<ваш-поддомен>.workers.dev/admin`, придумайте пароль,
   добавьте лекарства и время приёма.
6. В разделе **«Телефон мамы»** скопируйте ссылку и отправьте маме. На её iPhone:
   1. открыть ссылку в **Safari**;
   2. «Поделиться» → **«На экран „Домой“»** → «Добавить»;
   3. открыть **«Таблетки»** с экрана «Домой» → **«Включить напоминания»** → «Разрешить».
7. Нажмите **«🔔 Проверить»** на странице настроек — маме должно прийти уведомление.
8. Чтобы вам приходили сообщения «закончились таблетки» и «пропущен приём» — нажмите
   **«Получать на этом устройстве»** (на iPhone сначала добавьте страницу настроек на экран «Домой» и откройте оттуда).

## Требования

- iPhone с **iOS 16.4** или новее (push-уведомления от сайтов появились в 16.4).
- Сайт обязательно открыть **с экрана «Домой»**, а не из Safari — иначе iOS не разрешит уведомления.

## Для разработчика

```bash
cd site
npm install
npm test                       # юнит- и интеграционные тесты
npx wrangler dev --test-scheduled   # локально: http://localhost:8787/admin
curl "http://localhost:8787/__scheduled?cron=*+*+*+*+*"   # вручную запустить проверку расписания
```

- `src/worker.js` — страницы, API и запуск по расписанию (cron каждую минуту).
- `src/schedule.js` — что и кому отправить в данную минуту (часовой пояс, повторы, пауза).
- `src/webpush.js` — Web Push: шифрование aes128gcm (RFC 8291) и VAPID (RFC 8292) на WebCrypto,
  без сторонних библиотек. VAPID-ключи создаются автоматически при первой настройке.
- `public/` — страницы (`admin.html`, `mom.html`), service worker (`sw.js`), иконки.
- Данные хранятся в Cloudflare KV одним JSON-документом.
