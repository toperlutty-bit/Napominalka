# 💊 Напоминалка — таблетки для мамы

Простое приложение для iPhone, которое каждый день напоминает выпить лекарства.
Крупный шрифт, большие кнопки, всё на русском.

## Что умеет

- **Экран «Сегодня»** — список лекарств на сегодня по времени. У каждого большая зелёная кнопка **«Выпила»**.
  Просроченные приёмы подсвечиваются оранжевым «Пора принять!». Вверху — «Принято 2 из 4».
- **Напоминания** — каждый день в назначенное время приходит уведомление со звуком.
  Прямо в уведомлении есть кнопки **«✅ Выпила»** и **«⏰ Напомнить через 10 минут»**
  (нужно нажать на уведомление и подержать) — открывать приложение не обязательно.
- **Повторные напоминания** — если приём не отмечен, телефон напомнит ещё раз
  (по умолчанию 2 раза с интервалом 15 минут; настраивается). После отметки повторы отменяются.
- **Лекарства** — название, дозировка («1 таблетка»), примечание («после еды»),
  несколько времён приёма в день, цвет для удобства.
- **История** за 2 недели: что выпито, что пропущено. Можно исправить отметку свайпом.
- **Настройки** — имя для приветствия («Доброе утро, мама!»), повторы, проверка уведомлений.

Все данные хранятся только на телефоне, интернет не нужен.

## Как установить на iPhone мамы

Понадобится Mac с бесплатной программой **Xcode** (из App Store) и кабель для iPhone.
Платный аккаунт разработчика не обязателен.

1. Скачайте этот репозиторий и откройте файл `Napominalka.xcodeproj` в Xcode.
2. Слева выберите проект **Napominalka** → вкладка **Signing & Capabilities** →
   в поле **Team** выберите свой Apple ID (кнопка *Add Account…*, если его там нет).
   Если Xcode пишет, что идентификатор занят, поменяйте **Bundle Identifier**
   на любой свой, например `com.ваше-имя.napominalka`.
3. Подключите iPhone кабелем, выберите его вверху окна Xcode и нажмите ▶︎ (Run).
4. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   выберите свой Apple ID → **Доверять**. На iOS 16+ также включите
   **Настройки → Конфиденциальность и безопасность → Режим разработчика**.
5. Откройте приложение «Таблетки», **разрешите уведомления**, добавьте лекарства.
6. Во вкладке «Настройки» нажмите **«Проверить: прислать уведомление»** — через 5 секунд должно прийти уведомление.

> ⚠️ С бесплатным Apple ID приложение работает **7 дней**, потом его нужно
> переустановить из Xcode (данные сохранятся). С платным аккаунтом разработчика
> (99 $/год) — год, и можно установить через TestFlight без кабеля.

## Советы, чтобы напоминания точно приходили

- Звук на телефоне включён, боковой переключатель не в беззвучном режиме.
- В режиме «Не беспокоить»/«Фокусирование» добавьте приложение в разрешённые.
- В **Настройки → Уведомления → Таблетки** включены «Звуки» и «Баннеры»
  (стиль баннера «Постоянно» — тогда уведомление не исчезнет само).

## Для разработчика

- SwiftUI, iOS 16+, без сторонних зависимостей.
- `Napominalka/MedicineStore.swift` — данные (JSON-файл в Application Support).
- `Napominalka/NotificationManager.swift` — планирование уведомлений:
  основное напоминание повторяется ежедневно (`UNCalendarNotificationTrigger(repeats: true)`),
  повторные — разовые на ближайшие дни только для неотмеченных приёмов
  (с учётом лимита iOS в 64 уведомления). Перепланирование происходит при каждом
  открытии приложения и при отметке приёма.
- Сборка проверяется в GitHub Actions (`.github/workflows/ios-build.yml`).
